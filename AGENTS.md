# AGENTS.md

Guidelines for agentic coding agents working on **rentia-mobile** — React 19 + Vite 6. See the root `AGENTS.md` for the wider Rentia workspace.

**This is a PWA (installable web app via `vite-plugin-pwa`), not a native app** — there's no React Native/Expo/Capacitor here despite the "mobile" name.

## Commands

```bash
pnpm run dev                    # port 3040
pnpm run build                  # tsc -b && vite build
pnpm run preview                # --port 3040
pnpm run lint
```

## Project structure

```
src/pages/{auth,dashboard,crm,chat,profile}/
src/components/{ui,layout}/
src/contexts/ src/hooks/ src/api/
src/sw/        # service worker — vite-plugin-pwa, generates into dev-dist/ and dist/
```

## Stack notes

- Tailwind via `@tailwindcss/vite` (Tailwind v4 plugin), not CDN and not a `tailwind.config` PostCSS pipeline.
- `socket.io-client` is a dependency — check `src/contexts`/`src/hooks` for the realtime connection before assuming REST-only.
- Data fetching via `@tanstack/react-query` + `axios`.

## Env vars

`VITE_API_URL` — backend base URL. `VITE_VAPID_PUBLIC_KEY` — Web Push public key, must match the backend's `VAPID_PUBLIC_KEY`.

## Notes

- Don't hand-edit `dev-dist/` or `dist/` — both are build/service-worker output, regenerated by `vite-plugin-pwa` on build.
